# Executive Summary

This assessment evaluates the security posture of the **Example Corp** web
platform. Testing was conducted against the staging environment over a
two-week engagement window.

The overall risk rating is **Moderate**. No critical vulnerabilities were
identified, but several medium-severity issues warrant remediation.

## Scope

- Public web application (`app.example.com`)
- Authentication and session management
- API surface (`api.example.com/v2`)

## Methodology

Testing followed an industry-standard methodology covering reconnaissance,
enumeration, exploitation, and post-exploitation phases.
